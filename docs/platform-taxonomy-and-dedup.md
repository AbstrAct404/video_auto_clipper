# 平台视频类型划分与重复率判定调研（2026-08）

> 目的：为 beidou-smart-clip 的"视频类型分析项"与"降重能力"提供各平台
> 规则依据。结论已落地为 `configs/platform_profiles.yaml`（加载器：
> `app/platform_profiles.py`；降重检测：`app/dedup.py`）。

## 1. 视频类型划分标准调研结论

| 平台 | 是否有公开官方划分标准 | 结论 |
|---|---|---|
| **bilibili** | ✅ 有 | 官方分区（tid）体系：20 个大区 + 子分区，投稿必须选分区；开放平台提供分区查询接口 |
| **抖音** | ❌ 无公开标准 | 只有创作者服务中心的内容标签/垂类（剧情、短剧、搞笑、生活、影视、情感等），按兴趣推荐 |
| **快手** | ❌ 无公开标准 | 同抖音，标签/话题体系，无固定分区 |
| **小红书** | ❌ 无公开标准 | 频道+兴趣标签（影视综、情感、时尚等），无视频分区表 |
| **Meta (Instagram/Facebook)** | ❌ 无 | 无内容分区，只有原创性准则（Original Content Guidelines） |
| **X (Twitter)** | ❌ 无 | Topics 兴趣订阅，无创作者分区；另有 Copypasta 反重复政策 |
| **YouTube**（降级补充） | ⚠️ 半公开 | 上传类目枚举（Entertainment/Comedy 等）+ Shorts 规格 |

**降级策略（用户要求）**：无公开标准的平台，退而从其创作者中心/热门
话题标签体系归纳常见类目，做 best-effort 映射；仍覆盖不到的补充
YouTube 作为参考平台。

### 1.2 B 站自制/转载二分（与判重强相关）

- 投稿类型二分：**自制**（个人原创/二次创作）vs **转载**（搬运/转载）；
- 无加工的纯片段截取、加字幕、录屏、授权搬运**不算自制**；
- **撞车规则**：同一内容多人投稿时优先保留画质更高者；
- UP 主版权保护计划：原创稿件被违规搬运时平台主动法律援助。

## 2. 重复率判定调研结论

### 2.1 通用判重路径（多级漏斗，先廉价后昂贵）

1. **文件指纹（MD5）**：所有平台第一级，改一字节即变，最初级；
2. **关键帧/抽帧指纹比对**：画面指纹库比对（含"九宫格抽帧"变体）；
3. **AI 同质化语义检测**：判"低成本二创/千号一面"，机器+人工审核，
   播放量达阈值后人工介入。

### 2.2 各平台差异化规则

| 平台 | 判重特点 | 处罚 |
|---|---|---|
| 抖音 | 三级查重（MD5→关键帧→AI 同质化）；原创者联盟计划全网侵权监测 | 降流量/下架/封禁 |
| 快手 | 社区管理规范按侵权/搬运处理，无公开阈值 | 降流量/下架 |
| **小红书** | **3 个月内出现重复内容即判搬运**；信誉分初始 10、上限 12，**低于 8 限流 100%**；严打低成本二创 | 限流/扣分/停用功能 |
| bilibili | 自制/转载二分；撞车保留高画质；版权保护计划主动维权 | 锁定稿件/封禁 |
| Instagram/Meta | unoriginal 内容移出推荐流；聚合类账号整体降权（2026-04 扩展至图片/轮播） | 移出推荐/账号降权 |
| X | Copypasta and Duplicate Content 政策，按 spam 处理 | 限制触达（不下架） |
| YouTube | reused content + repetitious content（2025-07 明确含批量生产）；Content ID | 禁变现/下架 |

### 2.3 对降重能力的要求映射

本地降重体检（`POST /v1/dedup/analyze`）对齐平台前两级判重：

- **MD5**：所有平台第一级 → 输出文件 MD5，发布前应确保与源片不同（重编码即改变）；
- **帧指纹（aHash 64bit）**：对应关键帧/九宫格比对 → 与参考片比对得相似度，
  ≥0.75 review、≥0.90 block（provisional 阈值，待标定）；
- **残留水印检测**：角落长期静态区域 → 搬运痕迹（各平台 AI 同质化重点）；
- **黑边检测**：letterbox 未重制 → 判重高置信特征。

判定为 review/block 时的降重建议（对应平台处罚规避）：重编码/改分辨率、
裁切黑边与角标、变速、镜像、更换 BGM 与封面；小红书额外注意 90 天时间窗。
